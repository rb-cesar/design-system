# Design System

Biblioteca de componentes React com Emotion. Cada componente tem uma página de documentação gerada
a partir dos tipos e stories interativas.

## Como usar

```tsx
import { ThemeProvider } from '@emotion/react'

import { createTheme, GlobalCSS, GlobalStyle } from '@/design/system'
import { Button } from '@/design/ui'

export function App() {
  return (
    <ThemeProvider theme={createTheme('main')}>
      <GlobalStyle styles={GlobalCSS} />
      <Button color="primary">Salvar</Button>
    </ThemeProvider>
  )
}
```
